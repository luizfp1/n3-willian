# Sistema de Cadastro em Python

Programa simples  para cadastrar pessoas, salvar os dados em arquivo JSON, buscar por campos de texto e listar registros ordenados.

# Funcionalidades
Incluir, alterar e excluir cadastros (`nome`, `cidade` e `idade`).
os dados ficam salvos no arquivo `dados.json`.
Pesquisa por texto busca parcial ignorando maiúsculas e minúsculas por `nome` ou `cidade`.
exibe os registros ordenados por nome ordem alfabética ou idade crescente.
